Privacy Policy — Remix Forge Publisher

Effective date: 17 August 2026

Remix Forge Publisher ("the App") is a personal, single-user desktop tool operated by its developer to publish the developer's own videos to the developer's own TikTok account. It is not distributed to, or usable by, anyone else.

1. Data the App accesses

  • TikTok account basics (display name, avatar, open ID) via the user.info.basic scope — used only to confirm which account is connected.
  • OAuth tokens issued by TikTok — used to authorize uploads.
  • Video files and captions created locally by the developer — uploaded to TikTok via the official Content Posting API.

2. Where data is stored

All data (tokens, configuration, videos) is stored locally on the developer's own computer. The App has no server, no database, and no analytics. Nothing is transmitted to any party other than TikTok's official API endpoints.

3. Data sharing

The App does not sell, share, or disclose any data to third parties. It does not collect any information about TikTok users other than the developer's own account.

4. Data deletion

Revoking the App's access in TikTok settings (Settings → Security → Apps and websites) immediately invalidates its tokens. Locally stored tokens can be deleted by removing the local configuration file. To request deletion of any data, contact the email below.
